# Robinhood Retail Investor Behavior Analysis

This project analyzes retail investor behavior on Robinhood, focusing on trading patterns, user activity trends, and correlations between market events and investor decisions.

---

## Overview

The analysis examines:
- Trends in retail investor activity over time.
- Popular stocks traded by retail investors.
- Correlations between market volatility and user behavior.
- Key moments influencing trading activity.

---

## Data Sources

The project uses several key datasets (not included in this repository due to confidentiality):
- Robinhood user holding data for multiple stocks.
- Stock market price data from Yahoo Finance.
- Trading activity metrics from 2018-2020.

---

## Dependencies

- `pandas`: Data manipulation and analysis.
- `numpy`: Numerical operations.
- `matplotlib`: Data visualization.
- `yfinance`: Yahoo Finance market data.
- `datetime`: Date handling.

---

## Analysis Components

1. **Data Loading and Preparation**
   - Processing CSV files.
   - Timestamp conversions.
   - Data aggregation.

2. **Exploratory Data Analysis (EDA)**
   - Analysis of top 6 stocks.
   - User holding patterns.
   - Trading volume analysis.

3. **Visualization**
   - Time series plots.
   - Percentage change analysis.
   - Combined returns and holdings visualization.

---

## Key Findings

- Tech and high-volatility stocks dominate the top-traded list.
- Retail investors show strong preference for stocks with heavy media coverage.
- Significant spikes in activity during major market events.
- Activity tends to peak during high-volatility periods.

---

## Usage

The analysis is structured as a Jupyter notebook, with sections clearly marked for:
- Data preprocessing.
- Analysis execution.
- Visualization generation.

### To run the analysis:
1. Ensure all dependencies are installed.
2. Use your own dataset to replace the missing files.
3. Update file paths in the notebook as needed.
4. Execute the notebook cells in sequence.

---

## Data Structure

The project expects CSV files containing:
- User activity metrics.
- Stock trading patterns.
- Market performance indicators.

**Note:** These files are not included in this repository due to confidentiality. Replace the paths in the notebook with your own data paths.
